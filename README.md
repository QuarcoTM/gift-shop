# Gift Shop

Independent project for an online store of thoughtfully curated gift sets.

## Project status

Initial setup. Product range, brand identity, and ecommerce implementation are not finalized.

## Scope

- Seasonal gift collections, starting with Christmas
- Year-round curated gift sets
- Product catalog, inventory, orders, and administration (planned)

## Infrastructure

- GitHub: private repository for application source code
- Supabase: separate organization and project (to be connected)

## Security

Never commit API secrets, private keys, credentials, or customer data to this repository.
